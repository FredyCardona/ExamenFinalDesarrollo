# Registro de prompts utilizados

**Proyecto:** Sistema de incidencias técnicas de laboratorio  
**Tecnologías:** Node.js, Sequelize, React y sesiones con cookies.

Este archivo contiene un resumen de las consultas que realicé con apoyo de IA durante el desarrollo y la revisión del proyecto. Los textos están redactados de forma resumida y no son transcripciones literales.

### Prompt 1. Desarrollo inicial del proyecto

Necesito resolver un ejercicio de Desarrollo Web donde se pide crear una aplicación para registrar incidencias técnicas. El proyecto debe utilizar Node.js, Sequelize y React, con inicio de sesión y dos roles: usuario y técnico. Ayúdame a generar una primera implementación funcional siguiendo los requisitos.

### Prompt 2. Organización de los archivos

Ayúdame a revisar la estructura del proyecto para trabajar el backend y el frontend por separado. También necesito identificar los archivos de configuración, las dependencias y los documentos que solicita el examen.

### Prompt 3. Instalación y pruebas del backend

Necesito comprobar si el backend funciona correctamente. Indícame cómo instalar las dependencias, ejecutar las pruebas y revisar los resultados, especialmente la regla que permite cerrar una incidencia solamente a su propietario o a un técnico.

### Prompt 4. Ejecución y revisión del frontend

Ayúdame a iniciar la aplicación de React y comprobar su conexión con el backend. Quiero verificar que se pueda iniciar sesión, seleccionar un equipo, registrar una incidencia y consultar su estado.

### Prompt 5. Comprobación de las funcionalidades

Ya pude iniciar sesión como usuario y registrar una incidencia. Necesito revisar si el cierre funciona correctamente y confirmar que el cambio de estado se refleja en la interfaz.

### Prompt 6. Revisión antes de entregar

Ayúdame a comprobar que el proyecto compile, que las pruebas pasen y que el archivo `.gitignore` excluya las dependencias, los archivos generados y las variables de entorno.

### Prompt 7. Control de versiones con Git

Necesito subir el proyecto a GitHub y cumplir el requisito de realizar al menos dos commits. Guíame para registrar el backend y el frontend por separado, verificar el historial y publicar el repositorio.

## Observaciones

La IA se utilizó para apoyar la implementación inicial, resolver dudas de configuración y orientar las pruebas y la publicación del proyecto. Durante la revisión ejecuté los comandos, comprobé el inicio de sesión, registré una incidencia y verifiqué su cierre.
